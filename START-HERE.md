# Start here: put William's website on GitHub

You do **not** need to write the code. It is already made for you.

The complete website is the folder named **photo-storefront**. Keep the files inside that folder together. The most important ones are:

- `index.html` — the main website page
- `style.css` — colours and layout
- `script.js` — the buttons and shopping bag
- `photos.js` — photo names, prices, and descriptions
- `images` — the picture folder

## Part 1: find your finished website folder

1. On your computer, open **File Explorer**. It is the yellow folder icon on the taskbar or Start menu.
2. Click the address bar at the top of File Explorer.
3. Copy and paste this, then press **Enter**:

   `C:\Users\abmjd\Documents\Codex\2026-10-17\can-x20\outputs\photo-storefront`

4. You should see `index.html`, `style.css`, `script.js`, `photos.js`, and an `images` folder. This is your website. Do not delete or rename the important files.
5. Double-click `index.html` whenever you want to look at the website on your computer.

## Part 2: create a GitHub account

1. Open a web browser and go to [github.com](https://github.com).
2. Click **Sign up**.
3. Follow the prompts to create an account and verify your email. Keep your GitHub password somewhere safe.

## Part 3: put your website onto GitHub

1. When you are signed in to GitHub, click the **+** near the top-right corner.
2. Click **New repository**.
3. In the box named **Repository name**, type: `william-nature-photos`.
4. Choose **Public**. This is needed for the free version of GitHub Pages.
5. Do not check any extra boxes. Click the green **Create repository** button.
6. On the next screen, click the words **uploading an existing file**.
7. Go back to the `photo-storefront` File Explorer window from Part 1.
8. Select the files and the `images` folder inside it. Drag them onto the GitHub upload page. Do not drag the outer `photo-storefront` folder itself.
9. Wait for all files to finish uploading. Scroll down and click the green **Commit changes** button.

## Part 4: make your website live

1. At the top of your GitHub repository, click **Settings**.
2. In the left-hand list, click **Pages**.
3. Under **Build and deployment**, change **Source** to **Deploy from a branch**.
4. Under **Branch**, choose `main`.
5. In the folder box beside it, choose `/(root)`.
6. Click **Save**.
7. Wait about two minutes, then refresh that same Pages screen. GitHub will show a website address. It will look similar to this:

   `https://YOUR-GITHUB-NAME.github.io/william-nature-photos/`

8. Click that address to see your live website.
